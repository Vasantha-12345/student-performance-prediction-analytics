# Student Performance Prediction and Analytics System

## Project Overview
This project analyzes student academic performance and predicts final marks using Machine Learning.

## Features
- Student performance analysis
- Attendance analysis
- Study hours analysis
- Assignment score analysis
- Final marks prediction
- Machine Learning model evaluation
- SQLite database and SQL queries
- Power BI dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SQLite
- SQL
- Power BI

## Machine Learning
A Linear Regression model is used to predict Final Marks based on:
- Attendance
- Study Hours
- Assignment Score
- Internal Marks

## Project Results
- Average Final Marks: 78.30
- Highest Final Marks: 97
- Lowest Final Marks: 54
- Average Attendance: 79.60
- MAE: 1.52
- R² Score: 0.92

## Project Structure
- `test.py` – Python source code
- `students.csv` – Student dataset
- Power BI dashboard – Student performance visualization
